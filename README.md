The funniest one-star review of the Moon in 120 characters or fewer.
`main.py` (Python 3.13 stdlib only, no network) writes the review to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after validating
it against the competition gate: UTF-8 text, 1–120 characters, not
whitespace-only, one line, plain ASCII, no control characters, and a
byte-exact write-back check.

The entry:

> One star. Pulls the entire ocean around twice a day and still can't pull itself together.

89 characters. The grievance is the tides — something only the Moon does —
and the laugh turns on "pulls the entire ocean around" against "can't pull
itself together", landing on first read with the punchline as the last
phrase. No craters, cheese or brightness joke.

## Run

```sh
python3 main.py
```
